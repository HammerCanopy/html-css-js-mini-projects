## 🚀 The Antidote To Tutorial Hell

You have watched hours of YouTube tutorials. You understand what a `div` is. You know how to change the background color in CSS. But when someone asks you to build a simple to-do list from scratch, you freeze. You are stuck in Tutorial Hell.

**HTML CSS JS Mini Projects** is the cure. This repository is a massive collection of over 100 small, beginner-friendly web projects. Each project is built using only vanilla HTML, CSS, and JavaScript. No frameworks. No libraries. No complex build tools. Just pure, fundamental web development.

This is not a collection of useless code snippets. Every project is a fully functional, useful application. You will build a digital clock, a weather app, a tip calculator, a quiz game, and a fully working music player. Each project comes with a complete, commented source code and a live demo. It is the perfect resource for self-taught developers who want to build a solid portfolio.

## ⚙️ Quick Setup

You don't need to install anything to view the code. But to run the projects locally:

```bash

git clone https://github.com/your-username/html-css-js-mini-projects.git

# Step 2: Navigate to a project folder
```

## 🧠 Under The Hood: The DOM API

The Document Object Model (DOM) is the interface between JavaScript and HTML. Every project in this repository is an exercise in DOM manipulation.

For example, in the digital clock project, we use `document.getElementById('clock')` to grab the HTML element. Then, we use `setInterval()` to run a function every second. Inside that function, we use the `Date` object to get the current time. Finally, we set `element.innerText = currentTime` to update the screen. 

This simple pattern (select, listen, update) is the foundation of all frontend development. By repeating this pattern 100 times, it becomes second nature.
